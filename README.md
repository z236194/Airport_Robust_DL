# Airport Robust Deep Learning System

## Goal
Robust uncertainty-aware deep learning for multi-source airport pavement monitoring under complex weather conditions.

## Architecture

### core/
Production-level research code:
- models
- training
- experiments
- uncertainty estimation

### sandbox/
Minimal experiments:
- synthetic data
- toy models
- uncertainty prototypes

## Principle
1. Sandbox generates hypotheses
2. Core validates hypotheses
3. Papers formalize results
